# Marcas dos bancos

Usadas somente para identificar os bancos dos documentos importados. As marcas
continuam pertencendo aos respectivos titulares.

- Bradesco: símbolo extraído sem alterar seus traços do SVG vertical oficial:
  https://assets.bradesco/content/dam/banco-bradesco/marca/static-files/icons/BRAD_VERTICAL.svg
  Guia: https://banco.bradesco/marca/index.shtm
- Nubank: https://github.com/simple-icons/simple-icons/blob/develop/icons/nubank.svg
- Mercado Pago: https://github.com/simple-icons/simple-icons/blob/develop/icons/mercadopago.svg
- Banco do Brasil, Caixa, Sicredi e Sicoob: SVGs sanitizados do catálogo
  `logos-bancos-br`, com proveniência em fontes oficiais/Open Finance:
  https://github.com/rzmt/logos-bancos-br

  - Banco do Brasil: https://www.bb.com.br/docs/pub/inst/img/LogoBB.svg
  - Caixa: https://consentimento.openbanking.caixa.gov.br/assets/images/logomarca_caixa.svg
  - Sicredi: https://www.sicredi.com.br/openbanking/app/assets/images/shared/logo/logo_sicredi_512.svg
  - Sicoob: https://sicoob-openbanking.s3.sa-east-1.amazonaws.com/icone-sicoob.svg

Os dois últimos SVGs vêm do Simple Icons, sob CC0 1.0 (texto em
SIMPLE-ICONS-LICENSE.txt). Somente a cor de preenchimento foi definida. Coleta:
06/11/2026. Os quatro ativos adicionais foram coletados em 08/11/2026 e são
usados apenas para identificação nominativa. Ver `TRADEMARK-NOTICE.md` e
`LOGOS-BANCOS-BR-LICENSE.txt`. Nenhum SVG carrega recurso externo ou script.
