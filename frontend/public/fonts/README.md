# Fontes locais

- Instrument Sans, variável 400–700: Instrument, SIL Open Font License 1.1.
  https://github.com/Instrument/instrument-sans
  Licença completa: instrumentsans-OFL.txt.
- IBM Plex Mono 400/500/600: IBM, SIL Open Font License 1.1.
  https://github.com/IBM/plex
  Licença completa: ibmplexmono-OFL.txt.

Somente latin e latin-ext, suficientes para português, inglês e espanhol.
Os WOFF2 da Instrument Sans foram obtidos do CSS oficial do Google Fonts em
06/11/2026 e preservam os unicode-range originais. As fontes são carregadas do
próprio domínio; nenhuma requisição ao Google é feita pelo aplicativo.
Os arquivos IBM Plex Sans anteriores permanecem para facilitar reversão.
