# shadcn/ui descartado

O projeto é Tailwind v4 puro, com os componentes escritos à mão em `frontend/src/ui`.
Adotar shadcn/ui traria Radix, CVA e a estrutura `components/ui` junto — uma troca
de arquitetura de UI que ninguém pediu, para resolver um problema que o projeto não
tem. Registrado só para não ser reproposto: é a sugestão automática para qualquer
app React com Tailwind.
